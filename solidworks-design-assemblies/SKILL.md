# SolidWorks 机械设计与装配

把机构想法转成经用户确认的设计方案，再交付独立原生零件、带真实配合的装配体和完整跑通的双击自动化入口。根据每次任务选择机构、参数、材料和零件数量，不复制某个案例的结构或尺寸。

## 必须遵守的约定

- 先对话、分析尺寸并提交设计汇总；用户确认后才开始 SolidWorks 建模。沿用会话中已确认的内容，不重复询问。用户后续明确修改的范围按新指示执行。
- 用户未指定 SolidWorks 版本时必须询问。只针对用户选定的版本执行，不自行选择版本，也不建立跨版本模板或 API 自动适配流程。
- SolidWorks 保持可见。通过 PowerShell、COM、VBScript 或 Python API 操作；禁止 Computer Use、鼠标点击和桌面图像识别驱动的操作。
- 自制件分别生成独立零件文件。标准件按“网上下载对应型号 → SolidWorks Toolbox → 自行简化绘制”的顺序获取。
- 装配必须含 SolidWorks 原生配合特征；仅写入位置变换或固定全部零件不等于建立装配配合。
- 默认只检查零件重建、原生配合和静态干涉。运动联动验证、运动仿真仅在用户明确要求时开展，不因机构含运动副而自动增加。
- 干涉是报告项，不是交付阻断项。发现干涉时记录结果并继续输出；不要为了消除干涉反复修改尺寸、重新生成几何或重建整套模型。
- 从实际交付的同一个 VBS 入口完整运行验证。单独运行成功的模块、语法检查或复用现成结果，都不能代替从头构建验证。

## 1. 对话与方案分析

阅读 [设计汇总规范](references/design-plan.md)。提取用户的输入、已有资料和已确认约束，只询问影响机构或尺寸选择的缺失信息，例如用途、负载、行程、速度、空间限制、精度及简化范围；按任务分批询问，避免一次列出无关问题。

用户只提供想法时，先分解机构功能与零件，再分析各零件结构、尺寸、连接和安装顺序。对于未给定的条件提出明确的建议值及依据，纳入待确认方案，不把假设冒充用户要求或标准规定。

联网核实所引用的标准和厂家数据，区分：设计计算值、标准或厂家尺寸、尺寸链推导值、明确的经验取值。资料互相冲突或尺寸链不闭合时，在方案阶段指出并提出修正，不在建模时悄悄改变关键参数。

## 2. 提交汇总并等待确认

按设计汇总规范输出可审阅的方案，至少包含：

- 机构组成、功能和整体布局；设计输入、假设及简化范围。
- 零件明细表：编号、名称、数量、自制件或标准件、标准件型号与获取计划。
- 各零件的结构与设计尺寸、单位、尺寸依据、关键接口和材料状态。
- 装配位置、基准、配合类型、轴向或角向定位、安装顺序及预期运动关系。
- 选定的软件版本、输出内容、检查范围和待确认事项。

保持问题、修改意见和最终批准方案可追溯。未获确认时可以继续资料查询和方案分析，但不创建零件或装配体。用户确认后直接进入实施，不再为已经批准的常规步骤逐项索要许可。

## 3. 准备并获取零件

阅读 [标准件获取规则](references/standard-parts.md) 和 [API 自动化规则](references/automation.md)。为本项目建立独立输出目录与构建记录，根据用户选定的版本核对安装位置、模板、运行环境和 COM 连接，保持一个明确、可见的目标实例。

按批准的方案获取标准件并建立自制件。下载模型若与批准接口不符，不能缩放凑尺寸或以近似型号冒充对应型号；按获取规则处理差异。自行简化的标准件仍须保证安装接口、包络及基本关键尺寸，标记来源和简化项。

自制件优先采用可编辑的原生草图、拉伸、旋转、切除、孔及阵列等合适特征。每种不同零件输出独立 `.SLDPRT`；相同规格的重复件复用零件文件，并在总装中形成多个实例。不要将全机做成一个多实体零件来替代装配体。

## 4. 建立装配与外观

选择稳定的装配基准，先放置基础件，再依据批准关系逐项建立同心、重合、距离、角度及必要的机械配合。组件变换可作为初始布置，最终检查必须读取实际配合特征及其引用。基础件可固定；其他组件按设计保留或约束自由度，不为消除欠定义提示而固定所有零件。

根据用户要求及零件用途设置外观。没有指定时采用可区分部件的合理工业外观，不把单个历史案例的颜色固化为通用配色。区分显示外观与物理材料属性，分别记录是否赋值。保证独立零件和总装中的最终外观均被保存。

## 5. 检查与交付

阅读 [验证与交付规则](references/validation-delivery.md)。检查独立文件、实体、特征重建和原生配合，执行一次最终姿态的静态干涉检查。检查失败与检测到干涉必须分开报告：无法完成检测不等于零干涉。

存在干涉时仍输出零件、装配体、脚本和报告，注明涉及零件、体积及可定位信息；不得把干涉列入自动重建循环。正常的特征更新或强制重建检查不等于重新设计或重新生成全部几何。

为本项目生成可双击的 VBS 入口及必要依赖。通过同一个入口在新的输出目录完整执行零件生成、标准件获取或缓存导入、真实配合、外观保存、静态检查与交付。修复实际出现的脚本错误，再验证受影响流程；不以修改几何来掩盖干涉报告。

交付 `.SLDPRT`、`.SLDASM`、VBS 及配套脚本/标准件缓存、设计汇总、验证记录和预览。说明 VBS 是否依赖其他文件、如何完整解压运行，以及已通过和未验证的项目。保留最后的 SolidWorks 模型供用户查看。录像、工程图、运动仿真等不属于默认输出，仅在用户要求时增加。
